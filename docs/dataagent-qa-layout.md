# Data Agent 问答体验：布局参考与调整

## 定位与现状

面向招聘方阅读的交互设计案例，保留现有编辑式排版、字体、主题变量与渐变展板，做局部优化。DESIGN_VARIANCE 5 / MOTION_INTENSITY 2 / VISUAL_DENSITY 3；不引入额外动效或组件库。

调整前，三列表格与下面的三段说明重复；界面全部置于长段落下方，设计判断与对应界面距离较远；持续对话的衔接出现在三环节展开之前。

## 参考案例

- [Cassandra Lim · Ardor Cloud](https://cassylim.com/ardor)：按设计决策组织方案，将提示框、聊天面板等具体界面与解释关联。借鉴决策与界面对应的叙事，不引用其项目数据或个人职责。
- [Casey Lin · ChangeGuide](https://hicaseylin.com/changeguide)：区分问题、设计问题、选择理由与取舍；明确设计建议和实际交付边界。借鉴判断依据的层级，不照搬完整长文结构。

参考页面仅用于编排研究，不作为本项目功能、访谈或成果的证据。

## 实施

1. 导语保留首次问答的目标；总览表压缩为「环节 / 用户关注 / 设计判断」，具体处理移入对应图文段落。
2. 三个环节采用左侧判断与两条交互规则、右侧渐变界面示意的布局。窄屏上下堆叠，不通过缩放让界面文字变小。
3. 文案去掉第一人称；贡献通过入口组织、澄清边界、状态信息层级、结果核查入口体现，不补造技术实现与效果指标。
4. 持续对话的衔接移到第三环节之后。保留全部既有章节 ID 和深链接，背景与演进、持续对话正文保持不变。
5. 双语文案继续由 `dataPilot.ts` 提供，页面与聊天共享设计说明，模拟界面内容仍排除于聊天事实。

## 验证

70 项测试与生产构建通过。浏览器检查桌面图文排版、390px 窄屏、深浅主题，确认总览表无需横向滚动、页面无横向溢出；验证推荐问题回填、步骤详情展开和报告／明细切换。
